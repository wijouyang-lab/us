# ATR 风险平价仓位 vs 固定仓位（2y PIT，20D 持有）

> 脚本：`tools/research/atr_position_sizing.py`
> 样本：**212,869** 行 / **443** 个 Scan_Date；每日取 `Momentum_20D_Pct` Top5
> 两策略**同池同票**，唯一差异是仓位权重 ✓

## 1. 结果对比

| 指标 | 固定仓位（等权 10,000/只） | **ATR 风险平价（10,000/ATR%）** | 差异 |
|---|---|---|---|
| 平均 20D 收益 | +95.07% | **+62.95%** | -32.12 pp |
| 日收益波动 | 11.643% | **10.469%** | -1.174 pp |
| **夏普\*** | **1.086** | **0.895** | -0.191 |
| **最大回撤** | **-24.72%** | **-19.99%** | +4.73 pp |
| 交易日数 | 23 | 23 | — |

`*` 夏普按日序列 × √(252/20)；**含 20D 重叠偏差（高估约 √20≈4.5 倍）** ✓

## 2. 权重分布（ATR 平价）

- 单票权重区间：**3.291% ~ 38.729%**（越分散说明 ATR 差异越大）
- 等权基准权重 = 20.0% ⇒ **ATR 平价显著偏离等权** ✓

## 3. 结论

- ✗ **ATR 平价未提升夏普**：1.086 → 0.895（-0.191）
- 回撤变化：-24.72% → **-19.99%**（**改善** ✓）
- 收益变化：+95.07% → +62.95%

## 4. ⚠️ 限制

1. **20D 前瞻重叠** ⇒ 夏普高估；绝对收益不可外推 ✓
2. 权重只按 `ATR_Pct` 归一，**未考虑相关性/行业集中** ✓
3. 未扣成本；未考虑资金约束（总仓位可能超 5×10,000）✓
4. 选股用 `Momentum_20D_Pct` 代理，**非生产严筛逻辑** ✓
