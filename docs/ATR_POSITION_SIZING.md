# ATR 风险平价仓位 vs 固定仓位（2y PIT，20D 持有）

> 脚本：`tools/research/atr_position_sizing.py`
> 最近一次在 GitHub Actions 实际生成：2026-10-20
> 样本：**212,869 行 / 443 个 Scan_Date**；每天取 `Momentum_20D_Pct` Top5；两种仓位方案同池同票，唯一区别是权重。

## 1. 结果对比

> 交易成本假设：每个完整 20D 持有期往返 **11.0 bps**，即进场滑点 5 bps + 出场滑点 5 bps + 双边佣金合计 1 bps。此数值是研究假设，不是券商报价。

| 指标 | 固定仓位（等权 Top5） | ATR 风险平价 Top5 | 差异 |
|---|---:|---:|---:|
| 平均单期 20D 毛收益 | +3.562% | +2.639% | −0.923 pp |
| **平均单期 20D 净收益** | **+3.452%** | **+2.529%** | −0.923 pp |
| **非重叠 20D 期累计净复利** | **+90.30%** | **+58.94%** | −31.36 pp |
| 非重叠 20D 净收益标准差 | 11.643% | 10.469% | −1.174 pp |
| **夏普（净收益）** | **1.052** | **0.857** | −0.195 |
| **最大回撤（净收益）** | **−31.59%** | **−25.59%** | +6.00 pp |
| 非重叠 20D 持有期数量 | 23 | 23 | — |

夏普按非重叠 20D 持有期收益 × `√(252/20)` 年化。单期收益代表 20D 持有期，不是日收益。

## 2. 权重分布

- ATR 平价单票权重区间：**3.291%–38.729%**。
- 等权基准权重为 **20.0%**。当前 ATR 权重分散程度较大，但这并不自动意味着净风险调整后收益更好。

## 3. 结论

在当前 Momentum Top5 研究样本和 **11 bps/每个 20D 往返**的成本假设下：

- 固定仓位的平均单期净收益与累计净复利均高于 ATR 风险平价。
- ATR 风险平价将最大回撤从 −31.59% 改善至 −25.59%，但净夏普从 1.052 降至 0.857；**回撤下降不等于综合风险调整后表现更优**。
- 这组结果不构成任何一方具有可交易 Alpha 的证明；它只比较当前研究口径下的仓位权重差异。

## 4. ⚠️ 限制

1. 原始 `Forward_Return_20D` 是每日滚动生成的 20D 前瞻收益；通过每 20 个 Scan_Date 抽样形成 **23 个非重叠期的近似**。它不是完整的逐日组合净值路径，且不能外推为实盘收益。
2. 已扣除每个被抽样 20D 持有期的往返 11 bps；仍未计入市场冲击、税费、融资/现金利息、流动性容量和真实订单滑点。
3. 权重只按 `ATR_Pct` 归一，未考虑股票相关性、行业集中和同时持仓的资金约束；按脚本假设名义仓位可能超过 5 × 10,000。
4. 选股使用 `Momentum_20D_Pct` 代理，并非生产 Scan 的完整严筛逻辑。
5. 在具备更完整逐笔成交、逐日组合权益曲线和稳健样本外验证前，不应用这些统计结果单独决定实盘仓位规则。
