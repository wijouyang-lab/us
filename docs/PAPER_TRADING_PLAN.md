# Paper Trading 计划（观察期从 2026-10-19 起）

> 账本：`portfolio_paper_transactions.csv`（**与实盘 `portfolio_50000_*` 完全隔离**）
> 观察日志：`portfolio_paper_observation_dates.csv`（记录 Scan 成功后实际运行的日期，包括零候选日）
> 日报：`docs/PAPER_TRADING_REPORT.md`（每日由 `scripts/paper_trading_report.py` 覆盖生成）
> 代码：`scripts/paper_trading.py`（记账） + `scripts/paper_trading_report.py`（统计）
> 自动化：`.github/workflows/paper-trading.yml`（scan 成功后自动运行并回写 main）

## 1. 模拟规则

| 项 | 设定 |
|---|---|
| 初始资金 | **50,000**（与实盘一致，便于对比） |
| 单笔仓位 | **10,000**（`UNIT`） |
| 最大同时持仓 | **5 只** |
| 信号日期 | pending 文件日期，单独存入 Signal_Date |
| 买入价 | 信号日之后第一根完整日线的开盘价（Open）；缺失时不成交，不回退旧收盘价 |
| 模拟成交 | 买入参考开盘价上浮 5 bps 滑点；卖出参考收盘价下压 5 bps 滑点 |
| 佣金 | 每边 0.5 bps（研究假设；不代表特定券商报价） |
| 卖出条件 A | 买入后第 **20 个实际有价格的交易日**收盘退出 |
| 卖出条件 B | 完整日线收盘价 ≤ 模拟成交买入价 × 0.95 时，按该收盘价减滑点退出 |
| 幂等 | Txn_ID = {Ticker}|{Signal_Date}|BUY；同一信号只创建一条生命周期记录 |

## 2. 评估标准（**必须全部达标才进实盘**）

| 指标 | 阈值 | 理由 |
|---|---|---|
| **观察期** | **≥ 40 个交易日** | 覆盖至少 2 个完整 20D 周期，避免单周期噪声 |
| **20D 胜率** | **≥ 55%** | 低于 55% 时，即使盈亏比可观，期望值也难稳定为正 |
| **盈亏比** | **≥ 1.2** | 与 55% 胜率搭配：0.45/0.55 ≈ 0.82 为盈亏平衡点，1.2 提供安全边际 |
| **期望值** | **≥ +0.5%/笔** | 覆盖双边交易成本（约 0.1-0.3%）后仍有净收益 |
| **盈亏平衡所需盈亏比** | **< 实际盈亏比** | 动态校验：`(1-胜率)/胜率 < 实际盈亏比` 才真正盈利 |
| **最大回撤** | **≤ -5%** | 5 万本金下，回撤 5% = 2,500，是心理与风控的可承受上限 |

**任一指标不达标 ⇒ 不进实盘。** 观察期内**不得**因为短期数据好坏而中途放宽标准。

## 4. 与实盘的隔离保证

1. **完全独立的 CSV**：`portfolio_paper_transactions.csv`（实盘用 `portfolio_50000_transactions.csv`）。
2. **零代码复用**：`paper_trading.py` 不 import 任何生产模块（`scan` / `review` / `portfolio_50000` / `quant_filter`）。
3. **零回写风险**：workflow 只 `git add` 两个模拟交易/报告文件及一个观察日志文件；不提交 `portfolio_50000_*` 实盘账本。
4. **初始资金相同**（5 万）以支持后期"paper vs 实盘"对照。

## 5. 已知偏差（必须随结论一起报告）

| 偏差 | 说明 |
|---|---|
| **样本量小** | 每日最多 5 笔，40 交易日理论上限 200 笔，实际可能远少（pending 常为空） |
| **开盘成交假设** | 用下一交易日首根完整日线 Open 模拟成交；待完整数据到齐后才写入，不等于真实订单回报 |
| **成本模型近似** | 当前用每边 5 bps 滑点 + 0.5 bps 佣金；券商费率、市场冲击与税费可能不同 |
| **幸存者偏差** | 只用 scan 当日通过的票，天然偏多头 |

## 6. 前置条件提醒

**paper 账本只有在 pending 非空时才会产生交易。** 若连续多日 pending 为空（严筛 0 通过），
账本会保持空仓 —— 这本身就是一个**有效信号**：**候选生成能力不足**，需回到严筛参数层排查，
而不是放宽评估标准。

| **旧账本纠正** | APA 在 2026-10-19 的旧记录使用 2026-10-15 收盘价，已标记为 VOID，保留原始价格与股数作为审计痕迹，不计入盈亏或持仓 |
| **历史数据重建** | 时区日期修复合并后，必须运行手动 Rebuild Quant Price History 工作流；需验证周末日期、重复键、Open 覆盖率与备份产物后，新的价格历史才能用于模拟成交 |
