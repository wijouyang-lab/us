# 动量因子时间顺序样本外筛查（研究用途）

> **状态：未获准用于生产。** 本报告是横截面因子诊断，不是完整交易策略回测，也不是实盘收益证明。源数据此前已用于其他探索性报告，因此后段测试期是按时间留出的数据区间，但不是从未查看过的严格盲测集。

## 数据与方法

- 输入：`research_backtest_sp500_pit_2y.csv`
- 样本：222,388 行、502 个股票代码、462 个信号日期；数据日期 2024-12-10 至 2026-10-14。
- 固定信号：`Momentum_20D_Pct`；按每日横截面比较高信号组与低信号组，各取 20%。
- 按日期顺序切分：训练段 257 日（2024-12-10 至 2025-12-18）、验证段 72 日（2026-01-21 至 2026-05-04）、测试段 93 日（2026-06-03 至 2026-10-14）。训练与验证、验证与测试之间各清除 20 个信号日，避免 20 日前瞻收益标签跨越区间边界。
- 各期限方向只使用训练段决定，并在验证段与测试段冻结：5D、10D 选择低动量方向；20D 选择高动量方向。
- 每日 Top-Bottom 收益差的 t 统计量使用 Newey-West HAC（滞后阶数 = 前瞻期限 - 1），用于缓解重叠前瞻标签的自相关问题。这里的收益仍是历史数据上的毛收益，未模拟生产准入、止损成交、滑点、佣金或真实可执行仓位。

## 测试期判读

| 期限 | 判定 | 含义 |
|---|---|---|
| 5D | 未确认 | 收益差为正，但 HAC t = +1.93，未达到本筛查采用的 +1.96 门槛 |
| 10D | 未确认 | 收益差为正，但 HAC t = +1.86，证据仍不足 |
| 20D | 显著负收益差 | 训练段选出的“高动量更好”方向在测试段反转；收益差 -1.864%，HAC t = -2.38 |

**结论：当前结果不支持把该动量信号直接用作生产选股依据。** 5D 与 10D 的正收益差尚未通过设定的统计筛查；20D 测试结果则与训练方向明显相反。不能在查看结果后反过来挑选测试期表现更好的方向，再宣称策略已通过样本外验证。

## 限制与下一步

1. 这是单因子横截面筛查，不包含生产中的硬门槛、Core/Observation 准入、组合约束、止损、成交延迟、滑点和佣金。
2. 资料中的 PIT 成分股日期规则不能保证消除全部退市偏差、公司行动或行情供应商问题。
3. 同一数据源已有其他全样本探索报告，可能存在研究者选择偏差；本结果应视为诊断，不是严格独立的最终检验。
4. 下一步应先修复并验证每日 `Technical_Date` 与真实交易日标签，然后在重新冻结的规则下运行净成本组合模拟和持续的纸面交易观察。此报告不会改动任何生产评分、推荐、止损或交易账本。
