## 2. 重点三例（本报告重点确认对象）

### MSTR 06-19 — `$965`
- Rec_Price=116.56，Stop=965，**8.28x**。`$965` 是同批次 **MU(1043.19)** 的止损（965/1043 = 0.93x 合理）。
- **首次异常日期**：2026-06-19（写入即错，非后续跳变）。
- **是否同一 lifecycle**：是（独立 Core_Dragon 生命周期）。
- **是否被后续 trailing stop 继承**：**是**——`get_trailing_stop_context` 的 `candidate=max(old_stop,candidate)` 使 965 成为永久 floor，从未被纠正；run3 在 09-29 以 stop=965 触发，Exit=161.63。
- **建议新 stop 来源**：ATR 技术止损 = Rec_Price × (1 − max(3%, min(12%, 2×ATR%)))，ATR% 缺失时用 3% 下限 → 约 113。

### BSX 06-25 — `$980`
- Rec_Price=44.21，Stop=980，**22.0x**。`$980` 是同批次 **MU(1048.51)** 的止损（980/1048 = 0.94x 合理）。
- **首次异常日期**：2026-06-25（写入即错）。
- **是否被后续 trailing stop 继承**：**是**——run3 在 09-29 以 stop=980 触发，Exit=44.15。
- **建议新 stop 来源**：ATR 技术止损 → 约 42.9。

### ORCL 06-26 — `$505`
- Rec_Price=149.74，Stop=505，**3.31x**。同批无同值（单记录污染），疑为同批 **AMD(532.57)** 的 ~5% 止损（≈506）误写，或 AI 幻觉。
- **首次异常日期**：2026-06-26（写入即错）。
- **是否被后续 trailing stop 继承**：**是**——run3 在 09-29 以 stop=505 触发，Exit=132.79。
- **建议新 stop 来源**：ATR 技术止损 → 约 145。
- **注意**：此例来源证据弱于 MSTR/BSX（无同批同值），但 Stop/Price=3.31x 明确越界，仍判定为异常。

## 3. 是否存在无法安全自动修复的记录

**存在 3 条，且正是上述 MSTR 06-19 / BSX 06-25 / ORCL 06-26。**
原因：这三条已在 run3 被错误触发并写入 `Status=Stop_Loss_Hit`（review_history.csv 对应 `移动止损清仓`）。修复它们需要**撤销已记录的 STOP_TRIGGERED** 并把 Status 回退为 Active——这违反"不要撤销已记录的 STOP_TRIGGERED"约束，属**必须人工确认**的敏感回写。
