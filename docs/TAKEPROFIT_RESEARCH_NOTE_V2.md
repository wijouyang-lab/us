# 止盈模块回测纪要 v2（2026-10-16）

> 状态：回测已完成，第二套底层信号（随机等权）仍太弱，止盈无法定论
> 样本：S&P500 PIT 10 年（1,047,578 行 / 2,472 天）
> 与 v1 的差异：选股从 ATR_Pct Top5 改为全池随机 20 只等权

## 1. 回测设计

- 选股：每日从 S&P500 全池随机抽 20 只（seed=42 可复现）
- 持仓：20 只等权（每只 5%）
- 止损：−8%
- 止盈规则：1 基准 + 3 固定 + 3 移动（与 v1 同引擎）

## 2. 结果

| 规则 | 交易数 | 平均收益 | 中位收益 | 胜率 | 年化夏普 |
|------|--------|---------|---------|------|---------|
| baseline_none | 2,721 | +0.669% | +0.642% | 53.2% | 0.27 |
| A_fixed_10 | 2,948 | +0.682% | +0.815% | 54.5% | 0.32 |
| **A_fixed_15** | 2,774 | **+0.896%** | +0.765% | 54.3% | **0.40** |
| A_fixed_20 | 2,772 | +0.801% | +0.549% | 52.9% | 0.34 |
| C_trailing_5 | 3,233 | +0.636% | −0.431% | 47.9% | 0.30 |
| C_trailing_8 | 2,846 | +0.887% | +0.497% | 52.3% | 0.37 |
| C_trailing_10 | 2,769 | +0.858% | +0.664% | 53.2% | 0.36 |

## 3. 核心结论

### 结论 1：随机等权（市场 beta）基准夏普仅 0.27

"全池等权 = 正期望强信号"的假设不成立。随机等权在 20 日视野 + 20 只分散下，夏普远低于可用阈值（>1）。

### 结论 2：v2 的信号性质优于 v1，但仍太弱

| | v1 (ATR Top5) | v2 (随机等权) |
|--|--------------|--------------|
| 基准夏普 | 0.47 | 0.27 |
| 中位收益 | −4.28% | +0.64% |
| 胜率 | 42.5% | 53.2% |

v2 是"弱正期望"，v1 是"噪声 + 少数大赢家"。**v2 更接近"可研究"的状态，但强度仍不够。**

### 结论 3：A_fixed_15 是两轮中唯一正向增量

- 夏普：0.27 → 0.40（+48%）
- 平均收益：+0.669% → +0.896%（+34%）
- 胜率：53.2% → 54.3%

**但绝对值 0.40 仍远低于可用阈值（>1）——不可交易。**

### 结论 4：移动止盈在两轮中均最差

C_trailing_5 交易数最多（3,233）、中位收益为负（−0.431%）、胜率最低（47.9%）、tp 触发 1,437 次——**过紧的移动止盈系统性截断盈利。**

## 4. 方法学警告

1. **交易序列回撤指标彻底失效**——7 套规则全部 ≈−100%，不能作为回撤对比
2. **未计交易成本**——A_fixed_15 换手仅 +2%，影响应小，但需验证
3. **信号用全样本 seed=42 随机**——可复现，但仍含市场 beta 与幸存者混合效应

## 5. 对生产的建议

| 建议 | 理由 |
|------|------|
| 不上线止盈模块 | 增量绝对值不可用（0.40 < 1） |
| 若未来有夏普 >0.8 的底层信号，重测 A_fixed_15 | 唯一正向证据值得在强信号上复验 |
| 不做移动止盈 | 两轮均最差，系统性截断盈利 |

## 6. 关键教训

**两轮止盈回测（v1 + v2）均无法给出可执行结论——根本原因是底层信号不够强。**

止盈规则有效性的验证，前提是底层信号本身可交易（夏普 >1）。当前所有候选信号（ATR_Pct、随机等权）均不满足此条件。

**止盈研究到此为止。下一步若要继续，必须先构造一个夏普 >0.8 的底层信号。**
