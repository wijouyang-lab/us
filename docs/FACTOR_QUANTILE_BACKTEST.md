## 1. 打分方法

- 每日（`Technical_Date`）**横截面百分位**（0~1）+ **方向化**（见下）
- **等权**相加 → `Composite`，再按日分 5 层（Q1 最低 → **Q5 最高分**）
- 方向（SIGN，来自 PIT 2Y 的 IC 符号，**in-sample**）：
  - `+1`：`ATR_Pct`、`Beta_60D_SPY`、`Volume_Ratio_20D`
  - `-1`（越高越优先做空/回避）：`Momentum_5D_Pct`、`Momentum_20D_Pct`、`Momentum_60D_Pct`、`RSI`、`MA20_Slope_Pct_5D`、`乖离率(%)`、`ZScore_20D`、`Stock_RS_20D_vs_SPY`、`KDJ_J`、`MACD_HIST_LAST`、`量比`

### ⚠️ 必读偏差提示

1. **方向来自 in-sample IC** ⇒ 存在前视乐观（真实 OOS 会更差）。
2. **Forward_Return 重叠**（每日都有 20 日前瞻）⇒ 夏普被高估约 √20（见 P0 加固经验）。
3. **未扣交易成本**；分层组合换手高，成本可能吞掉全部价差。
4. 本报告只说明**因子打分的横截面区分度**，不等于可交易策略。
