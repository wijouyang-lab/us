## 3. BP 归因回归（控制 Size 与 Sector）

> 样本 **118,353** 行；Size 用 `log(Price)` **代理**（无市值字段 ✗）

| 模型 | BP 系数 | **BP 的 t 值** | R² |
|---|---|---|---|
| 仅 BP | -0.000005 | **-0.85** | 0.00001 |
| BP + Size | -0.000003 | **-0.41** | 0.00040 |
| BP + Size + Sector 哑变量 | 0.000008 | **+1.23** | 0.01825 |

### 判读

- 仅 BP：t = **-0.85**
- 控制 Size + Sector 后：t = **+1.23**
- **⇒ 控制风格后 BP 不再显著（|t| < 1.96）⇒ BP 的收益来自 Size/行业风格，不是 BP 本身** ✗✓
